# 입문서 추가 글꼴 출처

확인일: 2026-09-22. 공식 원본 파일을 그대로 자체 호스팅한다.

- Paperlogy: 기존 `paperlogy/` 폴더의 출처/라이선스 고지 참조.
- NanumGothic Regular: https://github.com/google/fonts/raw/refs/heads/main/ofl/nanumgothic/NanumGothic-Regular.ttf
  - 라이선스 원문: https://github.com/google/fonts/raw/refs/heads/main/ofl/nanumgothic/OFL.txt
  - `nanumgothic/OFL.txt`를 함께 배포한다.
- LeeSeoyun: https://www.heungkuklife.co.kr/front/company/fontDownload.do?seq=LeeSeoyun.ttf
  - 공식 사용 조건: https://www.heungkuklife.co.kr/jsps/front/company/ci/digit-hand-font-info.jsp
  - 웹/앱 및 폰트 파일 임베딩 허용. 유료 판매, 임의 수정·개작 재배포 금지. TTF를 변환하지 않았다.
  - 확인한 고지는 `leeseoyun/LICENSE-ko.txt`에 보관했다.
- Outfit (Variable, 100-900): https://github.com/google/fonts/raw/refs/heads/main/ofl/outfit/Outfit%5Bwght%5D.ttf
  - 라이선스 원문: https://github.com/google/fonts/raw/refs/heads/main/ofl/outfit/OFL.txt
  - `outfit/OFL.txt`를 함께 배포한다. 표지(bookCover)의 영문 라벨과 R/L/W/S 블록에 쓴다. 확인일 2026-10-23.
- SUIT Medium/Bold (static woff2): https://cdn.jsdelivr.net/gh/sun-typeface/SUIT@2/fonts/static/woff2/
  - 라이선스 원문: https://github.com/sun-typeface/SUIT/blob/main/LICENSE (SIL OFL 1.1), `suit/OFL.txt`. 교재 제목에 쓴다. 확인일 2026-10-23.
- MaruBuri Regular/Bold (woff2): https://hangeul.pstatic.net/hangeul_static/webfont/MaruBuri/
  - 라이선스: 네이버 나눔글꼴 라이선스 안내 https://help.naver.com/service/30016/contents/18088 (마루 부리 포함, SIL OFL 1.1). 안내문의 저작권 문구와 OFL 원문을 `maruburi/OFL.txt`에 보관. 교재 본문에 쓴다. 확인일 2026-10-23.

- Noto Sans KR (Variable, 124개 유니코드 조각 woff2): Google Fonts CSS2 API `https://fonts.googleapis.com/css2?family=Noto+Sans+KR:wght@400;500;700;800` 가 내려주는 fonts.gstatic.com v40 파일을 그대로 받았다.
  - 라이선스 원문: https://github.com/google/fonts/blob/main/ofl/notosanskr/OFL.txt (SIL OFL 1.1), `notosanskr/OFL.txt`. 글꼴 이름은 `NotoSansKRBook`(css/book-font-notosanskr.css). 단어장 표지(bookCover, 단어장 디자인)에 쓴다. 확인일 2026-10-28.
