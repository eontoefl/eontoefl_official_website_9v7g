# 공홈 인증 모듈 격리 시험 (보안작업 묶음2 계약 3A)

`js/auth-session.js`(새 로그인 스위치·인증 모듈)가 꺼져 있을 때 아무것도 하지 않는지, 켜져 있을 때 기존 요청의 자격과 기존 로그인 상태를 건드리지 않는지 본다. 기준 커밋은 `d39c0ee`.

## 세 가지

1. **회귀시험 `run.mjs`** — 전부 가짜(가짜 화면·가짜 저장소·가짜 시계·가짜 서버). 실제 네트워크 요청 0건.
2. **화면 시험 실행기 `screen.mjs`** — 실제 브라우저(Chromium)로 절차를 돌린다. `--fake`(가짜 서버 상대 — 작업방이 돌린 것)와 `--real`(시험 프로젝트 `hmncdheiwqwekdbtijar` 상대 — 브레인방만). 순서와 멈춤은 `절차.md`.
3. **로컬 서버 `serve.mjs`** — 손으로 화면을 볼 때만 쓴다(실행기는 같은 몸통 `serve-core.mjs` 를 스스로 띄운다).

가짜 화면·가짜 서버에서 통과한 것은 실제 서버에서 된다는 증거가 아니다.

## 회귀시험 실행

저장소 폴더에서, Node v26. 설치할 것은 없다.

```
node tests/auth-session/run.mjs
```

통과하면 마지막 줄이 `결과: 통과`, 종료 코드 0. 하나라도 어긋나면 `결과: 실패`, 종료 코드 1.

보는 것:

- 계약 1 회귀시험(`tests/supabase-config-headers/`)을 다시 돌린다 — 비교 1,620건·요청 1,458건·차이 0.
- 글자: 저장소의 스위치 값이 꺼짐, 켜는 길이 값 비교 한 줄뿐, 기준에서 바뀐 파일의 범위, 인증 모듈을 싣는 화면(`index.html`·`login.html` — head 에서), 헤더 함수에 등급을 넘기는 호출 0, 로그아웃·갱신이 "그 기록의 것"을 지정하는 한 곳.
- 꺼짐 × 저장소 상태 다섯 × 화면 동작 13가지를 기준의 파일로 돌린 기록과 대조. 인증 모듈을 싣지 않는 화면의 대조(130건).
- 기존 래퍼 요청: 계약 1 의 입력 1,620건 × (꺼짐, 켜짐 로그인 전·확인됨·거절) × 저장소 상태 다섯.
- 켜짐의 인증 동작(가짜 로그인 서버, SDK 사본은 실제 파일) 15묶음: 로그인, 이동 직전의 재확인, 주소의 로그인 정보, **응답을 붙잡은 동안 표시 0·첫 그리기부터 숨김**, signed_in 이 되지 않는 13가지, **한 시도의 실패 처리가 다른 로그인을 건드리지 않음**, **갱신 거절과 끝남의 구분**, 알림마다 갱신을 일으키지 않음, **로그아웃의 결과**, 옛 값, 상태 다섯, 자격 조건, 공개 키로 떨어지지 않음, 관리자 표시, 두 탭.
- 감도: 일부러 바꾼 사본 51개. 변조마다 **겨냥한 판정이 깨져야** 검출로 센다(사본이 예외로 죽은 것은 세지 않는다).
- 로컬 서버의 몸통(내줄 수 있는 모든 파일을 꺼짐·켜짐으로 한 번씩, 기록에 자유 형식의 글자 없음), 차단기(요청 34가지).

## 실행기 (가짜 서버 상대)

```
B3A_PLAYWRIGHT=<playwright-core 폴더>  B3A_CHROMIUM=<chrome.exe>  node tests/auth-session/screen.mjs --fake
```

경우 33개(P, 1~8, 9·9b, 10, 12, T, 14, 15, AF, 17·18·19a·19b, R1~R3, I1~I4, O1~O5)를 돈다. 가짜 서버의 답은 실행기 안에서 만들어지고, 브라우저는 `127.0.0.1` 말고는 이름을 풀지 못하며, 실행기가 여는 연결도 로컬뿐이다(결과의 `independentEvidence`).

## 파일

- `run.mjs` — 회귀시험. `world.mjs` — 파일 묶음(기준·작업본·내줄 사본)과 가짜 세계. `browser.mjs` — 가짜 브라우저. `fake-supabase.mjs` — 가짜 로그인 서버.
- `screen.mjs` — 화면 시험 실행기. `request-log.mjs` — 차단기(보내기 전에 가르기 — 목적지 + 자격의 종류·용도)와 가린 기록.
- `rewrite.mjs` — 내줄 때 바꾸기(주소·공개 키 → 시험 프로젝트, 스위치)와 운영 흔적 찾기. `serve-core.mjs`·`serve.mjs` — 로컬 서버(127.0.0.1).
- `절차.md` — 브레인방의 화면 시험: 환경 변수, 실행, 멈춤마다 할 일, 결과 읽는 법.

## 지키는 것

- 저장소의 스위치 값은 꺼짐이다. 켜는 길은 로컬 서버가 내주는 사본뿐이다(저장소의 파일은 바꾸지 않는다).
- 가짜 서버의 계정·JWT 모양의 값은 전부 지어낸 것이다. 출력·결과에 JWT 모양·공개 키·비밀번호를 적지 않는다.
- 계약 1 회귀시험은 "헤더 함수의 이름을 쓰는 다른 파일"을 찾는다. 그래서 이 폴더의 파일은 그 이름을 글자 그대로 적지 않는다(`run.mjs` 는 이어 붙여 쓴다).
